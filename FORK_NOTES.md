# Fork Notes

The Morpho Blue fork is the vendored `lib/lend` dependency (core `src/LidoLend.sol`), pinned as a git submodule and imported through the `@lido-lend/` remapping. This repository adds Lido extensions in `src/` on top of it.

The fork point, core changes, and layout rules live in `lib/lend/FORK_NOTES.md`.
