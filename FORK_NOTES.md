# Fork Notes

The Morpho Blue fork is the vendored `lib/lido-lend` dependency (core `src/LidoLend.sol`), pinned as
a git submodule and imported through the `@lido-lend/` remapping. This repository adds Lido
extensions in `src/` on top of it.

The fork point, core changes, layout rules, and license record live in `lib/lido-lend/FORK_NOTES.md`.
